Fix Installation Files

For a fresh installation or an update that says index.html is missing. This checker looks for required paths in the folder you choose. It never opens reports or changes files. Follow the recovery steps below if a file is missing.

1 · Check the extracted folder

Use Microsoft Edge on Windows. Select the extracted Service Operations Dashboard folder that contains 00 - OPEN DASHBOARD.html and System Files. If you select System Files directly, the checker can still verify its application files.

No folder selected. Nothing has been changed.

2 · Fix a missing application file

  1. Close all Dashboard tabs. Do not delete or overwrite your current folder, especially System Files/Workspace.
  2. Download the official Stable clean-install ZIP.
  3. In File Explorer, right-click the ZIP and choose Extract All into a new, empty folder. Do not open the launcher from inside the ZIP.
  4. Open the newly extracted Service Operations Dashboard folder and run the checker above. For a fresh installation, open 00 - OPEN DASHBOARD.html in Edge after the check passes, then complete Guided Setup.

Existing store? Do not import or copy a prior Workspace into the new installation or replace old files based only on this checker. Preserve the original folder and backups; use the Dashboard's verified update/recovery process or get an installation-specific recovery plan.

Expected layout

Service Operations Dashboard/
├── 00 - OPEN DASHBOARD.html
├── INSTALLATION-MANIFEST.json
└── System Files/
    ├── index.html
    ├── assets/
    │   └── app.js
    └── Workspace/  (protected local data)

Use System Files when the updater asks for the application root. Guided Setup uses a separate Workspace folder for store data. A missing index.html points to the application folder or extracted files. Guided Setup and SAPR imports do not create this file.
