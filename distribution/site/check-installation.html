Check installation files

For a fresh installation or an update that says index.html is missing. This check only reads filenames from a folder you explicitly select. It does not upload files, change any file, or access dealership reports.

1 · Check the extracted folder

Select the Service Operations Dashboard folder that contains 00 - OPEN DASHBOARD.html and System Files. Use Microsoft Edge on Windows.

No folder selected. Nothing has been changed.

2 · Fix a missing application file

  1. Close all Dashboard tabs. Do not delete or overwrite your current folder, especially System Files/Workspace.
  2. Download the official Stable clean-install ZIP.
  3. In File Explorer, right-click the ZIP and choose Extract All into a new, empty folder. Do not open the launcher from inside the ZIP.
  4. Open the newly extracted Service Operations Dashboard folder and run the checker above. Then open 00 - OPEN DASHBOARD.html in Edge and complete Guided Setup for a genuinely new store.

Existing store? Do not import or copy a prior Workspace into the new installation or replace old files based only on this checker. Preserve the original folder and backups; use the Dashboard's verified update/recovery process or get an installation-specific recovery plan.

Expected layout

Service Operations Dashboard/
├── 00 - OPEN DASHBOARD.html
├── INSTALLATION-MANIFEST.json
└── System Files/
    ├── index.html
    ├── assets/
    │   └── app.js
    └── Workspace/  (protected local data)

An updater checking the application root needs System Files, not the outer Dashboard folder and never the Workspace. A missing index can also mean the installer selected the wrong folder—not that the BMW SAPR report needs setup.
