Check your MoonDog installation

One local check for missing application files and update-recovery problems. Nothing gets installed, deleted, uploaded, or changed during this check.

1 · Choose the existing installation

On the computer with MoonDog installed, open this page in Microsoft Edge and select the outer folder containing 00 - OPEN DASHBOARD.html and System Files. Do not select Workspace.

No folder selected. Nothing has been changed.

2 · Repair approved software only

  1. Close all Dashboard tabs. Do not delete or overwrite your current folder, especially System Files/Workspace.
  2. For an existing installation, use the verified software repair tool (open the link, download the raw HTML file, then open it in Edge). Select the same outer MoonDog folder. It uses a verified package and preserves Workspace.
  3. If the check reports a missing, unreadable, or interrupted recovery journal, stop. Do not delete, rename, or invent a backup journal to make an update pass. Preserve the folders for local recovery review.
  4. Only for a brand-new store with no existing data, download a fresh Stable ZIP and extract it to a new folder. Never overwrite a working store's installation with a ZIP.

Existing store? Preserve the original installation and its Workspace. A read-only path check is not proof that an update is safe; unresolved backups must be reviewed before any repair.

Expected layout

Service Operations Dashboard/
├── 00 - OPEN DASHBOARD.html
├── INSTALLATION-MANIFEST.json
└── System Files/
    ├── index.html
    ├── assets/
    │   └── app.js
    └── Workspace/  (protected local data)

Use System Files when the updater asks for the application root. Guided Setup uses a separate Workspace folder for store data. A missing index.html points to the application folder or extracted files. Guided Setup and SAPR imports do not create this file.
