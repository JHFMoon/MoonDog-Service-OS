What stays local

Store identity, advisor and technician mappings, imported reports, RO/VIN/customer information, settings, history, exports, diagnostics, and backups stay under System Files/Workspace in your extracted copy. Software updates are not allowed to overwrite that workspace.

Updates

The dashboard can check the public Stable channel when internet is available. It verifies the release package and SHA-256, shows the planned application-file changes, requires approval, creates a rollback backup, verifies the installed bytes, and leaves Workspace data alone.

Browser target

The validated desktop target is Microsoft Edge on Windows with the File System Access API. Normal operation is offline after installation; internet is only needed for update checks.

Important: back up the extracted folder. The application is intentionally local-first; GitHub is not a backup of your store data.
