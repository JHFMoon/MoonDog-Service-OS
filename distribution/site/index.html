Need help before you start?

I don't know where MoonDog is saved

Try this on the computer where you normally open MoonDog:

  1. Find the MoonDog shortcut or the file you normally double-click to open it.
  2. If it's a shortcut, right-click it and choose Open file location, if that option is shown.
  3. Look for a folder that contains both of these items:
📁 Dashboard Interface 📄 00 - OPEN DASHBOARD.html 📁 System Files

Choose the outer folder (shown here as “Dashboard Interface”), not the “System Files” or “Workspace” folder inside it. Your folder may have a different name.

If you cannot find it, stop and ask the person who installed MoonDog. Do not create a new folder to replace it.

I see a message about a previous update or missing backup

Stop before repairing. An unfinished update or missing recovery record can mean MoonDog needs an assisted recovery. Keep the original folder and every backup exactly as they are.

Use the safe check above first. If it reports UPDATE BLOCKED, contact your MoonDog support person. Do not delete or rename backup folders.

I'm setting up MoonDog for the very first time

The repair check is for an existing installation. If this is a truly new store with no MoonDog data, use the guided fresh-installation steps and verify the Stable download before extracting it.

Do not use a fresh download to replace an existing MoonDog folder or store. Ask your installer if you're unsure.

I'm following instructions for an older version

Only if MoonDog 0.10.16 explicitly says “Editing authority is required before installing an update”, use the 0.10.17 bridge instructions. This is not a general repair tool.

Where do I get the approved repair tool?

Check the installation first. If the result says a previous update needs review, stop and use safe recovery help. Do not run a repair tool.

For a check that reports missing application files but no unresolved recovery problem, open Get verified repair tool right here on the MoonDog website. There is nothing to download from GitHub. The tool separately checks your installation, offers a verified Beta software repair, and asks for your permission before changing any program files.

If those instructions are unfamiliar, ask your MoonDog support person to guide you. Do not download other files or manually replace folders.

Your information stays yours

The check reads only the MoonDog folder you choose. It does not upload customer records, change files, install anything, or erase backups. A later repair is a separate action requiring your permission.

A successful folder check confirms that expected paths exist, not that the software is fully healthy or an update is safe. Recovery problems still require a local review.
