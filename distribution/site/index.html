Repair what is safe, never guess at recovery

The verified repair tool can restore approved application files and missing software folders while preserving the existing System Files/Workspace. It checks installation identity, package integrity, folder authority, and recovery backups before writing.

If a rollback backup is unreadable or missing its journal.json, MoonDog must stop and ask for local review. An unknown recovery state is not safe to erase, invent, or ignore. Do not delete backup folders to force an update.

Already using MoonDog?

After a verified repair, reopen the local launcher and use Settings → System Updates. Do not create a second Workspace or copy store data into a new installation to work around a failed recovery check.
