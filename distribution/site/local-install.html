MoonDog Service OS · Windows and Microsoft Edge

Install MoonDog on your computer

Choose a location on your computer. MoonDog will download its verified software and install a complete, separate application folder there. Your future reports, settings and Workspace stay in that folder—not on the MoonDog website.

No ZIP download, ZIP picker, or extra installation mode to choose. Guided Setup happens inside your installed application.

Checking the official MoonDog release…

1. Confirm a new installation

2. Identify your dealership

Enter only the dealership's basic identity. These details will be saved to the chosen computer's private MoonDog Workspace, not uploaded with the software or included in its public installation manifest.

3. Choose where to install

Choose an existing parent folder when Edge asks. MoonDog creates the new named subfolder there. Edge may refuse Desktop itself and protected system folders. Existing folders are never overwritten.

Privacy and sync: For a computer-only Workspace, choose a folder on a local drive that is not OneDrive-synced. Selecting a OneDrive-synced folder can cause Windows to upload its contents to your OneDrive account. MoonDog cannot see or enforce the full Windows path. If you intentionally use sync, avoid simultaneous editing from multiple computers and maintain a separate verified backup.

Finish the setup in order

  1. Installed: Official Stable software was downloaded, hashed and verified on this computer.
  2. Identity saved: Your dealership name, store code, optional brand and time zone are in this installation's private Workspace.
  3. Launch: In File Explorer, open the folder you selected and double-click 00 - OPEN DASHBOARD.html; use Microsoft Edge if asked.
  4. Authorize this folder: On first launch, choose that same outer installation folder once more when Edge requests local access.
  5. Verify your reports: In Guided Setup, import and review a SAPR report for the correct dealership. Until then, MoonDog must not claim complete operational readiness.
  6. Protect your work: After Guided Setup, create and independently verify an external backup outside the active Workspace.

Why one launch step remains: Edge does not let an internet website open an arbitrary local file:// program or silently grant the local program file access. That step cannot safely be automated by a website without a separately approved native launcher.

Optional: put MoonDog shortcuts on your Desktop

In Windows File Explorer, hold Alt while dragging each original file or folder onto the Desktop. This creates a shortcut without moving anything in the installation folder.

  1. Open MoonDog: 00 - OPEN DASHBOARD.html in the installed folder.
  2. Drop Reports Here: System Files / Workspace / 01 - DROP REPORTS HERE.
  3. Files to Learn: System Files / Workspace / Files To Learn. The website installer created this folder empty; Alt-drag the original, not a duplicate. It holds sources MoonDog could not recognize; normal reports belong in Drop Reports Here.

Leave the original launcher and Workspace folders in place. Only create Windows shortcuts with Alt-drag. Moving originals or copying prebuilt .lnk files with unknown targets can break file access.

About the included README: The official immutable Stable package's START HERE file also describes the manual ZIP-extraction alternative. You used the website installer, so there is no ZIP to extract again.

About versions: INSTALLATION-MANIFEST.json records this original Stable installation. Later verified in-app updates can change the current software version without rewriting that original baseline. Check the running version inside MoonDog.
