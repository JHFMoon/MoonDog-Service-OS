MoonDog Service OS · Windows and Microsoft Edge

Install MoonDog on your computer

Choose a location on your computer. MoonDog will download its verified software and install a complete, separate application folder there. Your future reports, settings and Workspace stay in that folder—not on the MoonDog website.

No ZIP download, ZIP picker, or extra installation mode to choose. Guided Setup happens inside your installed application.

Checking the official MoonDog release…

1. Confirm a new installation

2. Choose where to install

Choose an existing parent folder, such as a folder inside Documents, when Edge asks. MoonDog creates the named subfolder. Edge may refuse Desktop itself and protected system folders. Existing folders are never overwritten.

No files have been created.

Installation verified on this computer

Open File Explorer, go to the location you selected, then open the newly created MoonDog folder. Double-click 00 - OPEN DASHBOARD.html and choose Microsoft Edge if asked.

On first launch, Edge may ask you to choose that same MoonDog folder once more to grant the local application access. Then complete Guided Setup and import your own verified SAPR report.

Why one launch step remains: Edge does not let an internet website open an arbitrary local file:// program or silently grant the local program file access. That step cannot safely be automated by a website without a separately approved native launcher.

Optional: put MoonDog shortcuts on your Desktop

In Windows File Explorer, hold Alt while dragging each original file or folder onto the Desktop. This creates a shortcut without moving anything in the installation folder.

  1. Open MoonDog: 00 - OPEN DASHBOARD.html in the installed folder.
  2. Drop Reports Here: System Files / Workspace / 01 - DROP REPORTS HERE.
  3. Files to Learn: once MoonDog creates its learning folder inside the Workspace, Alt-drag that existing folder. Do not make a duplicate or replacement folder.

Leave the original launcher and Workspace folders in place. Copying or moving unverified prebuilt Windows .lnk files could make shortcuts point to the wrong folder.

This installs the official verified Stable software. Newer Beta versions, if appropriate, remain a separate in-app verified update decision. Do not clear or replace an existing MoonDog folder.
