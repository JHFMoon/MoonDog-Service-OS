Fresh installation · Step-by-step

Set up MoonDog for a brand-new store

Follow these steps on a Windows computer. You won't need to understand computer files to get started. Your store's information stays on that computer.

Already used MoonDog at this store? Stop here and choose Fix my existing MoonDog. Fresh installation does not recover old work, reports, settings, or backups.

1. Confirm this is really a new installation

Every dealership needs its own separate MoonDog folder. Do not install into a folder that another store already uses.

Use Windows with Microsoft Edge. You can read this guide on your phone or Mac, but the tested setup steps and folder permissions target Windows with Edge.

2. Download the official MoonDog software

MoonDog's Stable version is the recommended starting point for a new store. Do not download the Beta repair tool to create a store.

3. Check your downloaded file

This step confirms that the download is complete and matches the official Stable release. It happens only on your computer; the ZIP is not uploaded anywhere.

Download the official ZIP first. Then select it above.

4. Create a new MoonDog installation folder

After verifying the ZIP, the website can create the complete software folder for you. Choose the parent location where you want it saved. MoonDog creates its own new child folder there and will never overwrite a folder that already exists.

Verify the official Stable ZIP first. No folder has been created.

MoonDog's files were created and verified. In Windows File Explorer, open the new folder you selected and double-click 00 - OPEN DASHBOARD.html with Microsoft Edge. The website cannot launch a local file for you.

When prompted, choose that same outer installation folder and allow access. Complete Guided Setup using the actual store name, store code and time zone, then import a validated SAPR report from that same store (required to finish setup). Advisors and optional reports can be refined afterward. Missing source figures remain unknown, not zero. Check Settings → System Updates for verified future releases; updates preserve the separate Workspace. Do not select Fresh Update unless you intend to reset that selected installation.

Can't use the automatic installer? Show manual extraction steps
  1. On Windows, open File Explorer (the yellow folder icon) and go to Downloads.
  2. Find the same ZIP you just verified. Right-click it and select Extract All…, then Extract. Do not open MoonDog inside the ZIP.
  3. Open the extracted folders until you find Service Operations Dashboard, containing 00 - OPEN DASHBOARD.html and System Files. (Windows may create one extra outer folder.)
  4. Move the complete Service Operations Dashboard folder into a safe, new and empty location for this store. Keep the whole folder together. Never copy it over a previous store's folder.

The Workspace starts empty. MoonDog creates your store's information during Guided Setup. Don't rename, delete, or merge a previous store's Workspace into this folder.

5. Finish Guided Setup in MoonDog

Guided Setup belongs inside the installed MoonDog app, not this public website. Its two required foundations are a verified store identity and a valid SAPR report from that store. Have the correct SAPR file available; optional imports and advisor refinements can follow later.

  1. In the new folder MoonDog created (or the folder you manually extracted), double-click 00 - OPEN DASHBOARD.html. Open it in Microsoft Edge.
  2. When MoonDog asks which folder to use, choose the same outer installation folder you created. Its name may be different; do not choose System Files or Workspace inside it.
  3. When Edge asks for folder access, choose Allow only if it shows the folder you just installed.
  4. Complete Guided Setup by saving the dealership name, store code and business time zone, then importing and verifying the required SAPR report for that same dealership. Optional advisor details and other reports can follow; missing metrics remain unknown until verified.
  5. Open Settings → System Updates to check for verified future releases. Stable is the starting channel; Beta availability does not automatically authorize a reset or migration.
  6. Keep the installation and backup folders. Use MoonDog's validated Backup & Recovery tools to establish backups before normal operation.

Ready for use: Once the local launcher opens, Guided Setup has saved the correct store identity and validated SAPR, and System Updates can verify its channel. All other missing reports remain unverified; do not mistake an empty dashboard for zero dealership activity.
