Fresh installation · Step-by-step

Set up MoonDog for a brand-new store

Follow these steps on a Windows computer. You won't need to understand computer files to get started. Your store's information stays on that computer.

Already used MoonDog at this store? Stop here and choose Fix my existing MoonDog. Fresh installation does not recover old work, reports, settings, or backups.

1. Confirm this is really a new installation

Every dealership needs its own separate MoonDog folder. Do not install into a folder that another store already uses.

Use Windows with Microsoft Edge. You can read this guide on your phone or Mac, but the tested setup steps and folder permissions target Windows with Edge.

2. Download the official MoonDog software

MoonDog's Stable version is the recommended starting point for a new store. Do not download the Beta repair tool to create a store.

3. Check your downloaded file

This step confirms that the download is complete and matches the official Stable release. It happens only on your computer; the ZIP is not uploaded anywhere.

Download the official ZIP first. Then select it above.

4. Put MoonDog in its own folder

  1. On Windows, open File Explorer (the yellow folder icon) and go to Downloads.
  2. Find the same ZIP you just verified. Right-click it and select Extract All…, then Extract. Do not open MoonDog inside the ZIP.
  3. Open the extracted folders until you find Service Operations Dashboard, containing 00 - OPEN DASHBOARD.html and System Files. (Windows may create one extra outer folder.)
  4. Move the complete Service Operations Dashboard folder into a safe, new and empty location for this store. Keep the whole folder together. Never copy it over a previous store's folder.

The Workspace starts empty. MoonDog creates your store's information during Guided Setup. Don't rename, delete, or merge a previous store's Workspace into this folder.

5. Open MoonDog and finish Guided Setup

  1. Double-click 00 - OPEN DASHBOARD.html inside the extracted folder. Open it in Microsoft Edge.
  2. When MoonDog asks which folder to use, choose that same outer Service Operations Dashboard folder—not System Files or Workspace.
  3. When Edge asks for folder access, choose Allow only if it shows the folder you just installed.
  4. Complete Guided Setup with the correct store identity. Do not import reports from a different dealership.
  5. Keep the installation and backup folders. Use MoonDog's validated Backup & Recovery tools to establish backups before normal operation.

That's it. Your software is installed when MoonDog opens, Guided Setup completes, and you confirm the correct store.
