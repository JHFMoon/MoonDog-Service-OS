# Website-installed MoonDog Workspaces

This source supports an explicit dealership enrollment path in Beta and preserves the legacy synthetic test path. Source capability is not evidence of actual-dealership deployment or James-device acceptance. Follow issue #899's current checkpoint and exact published-main browser evidence before declaring readiness.

- Installation downloads and verifies the official Stable ZIP before reserving a fresh physical store UUID. A dealership Workspace additionally requires explicit name, store code, brand (optional), time zone and consent; it verifies, stages and activates the published Beta before saving a launch pointer. Missing configuration, failed checksums or insufficient known capacity fail closed. No employee, report, target or business zero is invented.
- The installer-confirmed dealership identity is fixed to that Workspace. Guided Setup still owns SAPR review, advisor participation, targets and management configuration. Use a separate Workspace/browser profile for another dealership. Ordinary labels do not enroll a store, and malformed enrollment records cannot fall back to synthetic authority.
- Application files are independently verified and read-only through the bridge. Only Workspace children can be modified. An exclusive Web Lock refuses duplicate owners. Existing application revision, journal and import-authority checks remain in place.
- Software candidates stage outside the original store and Workspace. Activation changes only an atomic selector. Explicit rollback/recovery verifies the original software. Download failures, corruption and incomplete candidates do not authorize fallback or private-data changes.
- Download the external backup file and keep its receipt separately, outside the browser profile. Recovery verifies every byte, receipt, software authority, logical Workspace identity and enrolled dealership configuration before restoring into a new empty physical store. Interrupted recovery remains held and unlaunchable. Clearing browser-origin data erases its private copy; persistence is not guaranteed.
- Legacy synthetic backup format/receipts and limits remain supported. Enrolled backups have a distinct authenticated format, up to12000 files/directories,64MiB per file and192MiB total. These are safety bounds, not a promise of browser quota or permanent storage.
- Report Inbox polling runs while MoonDog owns the Workspace. Closing the browser stops polling; reopening resumes checks. Unsigned reports require the application's exact store/source review and durable duplicate prevention. No closed-browser scheduler is promised.
- The service worker caches only an enumerated public shell, never Workspace data or exports. Private files are not uploaded or served as public URLs. The modules mirror `src/pwa` byte-for-byte and all entry/version URLs must match the immutable shell.

Use isolated synthetic profiles for Linux Chromium and Windows-hosted Edge acceptance. Hosted Windows proof is not proof on James's own computer. No Stable promotion, existing local-store migration, actual dealership deployment, recurring coding task or protected workflow change is authorized by this source alone.
